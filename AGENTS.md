# Repository UI & Design Rules

All human contributors and AI coding agents working on this repository must obey the following rules for every UI change, tool page, shared component, or static page:

1. Before building or changing any UI, read `docs/design.md` completely.
2. Follow the existing design and layout exactly. Do not create a new design, layout, colour, font, radius, shadow, icon style or component variant. Reuse the shared components and tokens.
3. If a required pattern does not exist in `docs/design.md`, stop, describe the need under 'Proposed additions', and wait for approval.
4. After building, run the verification steps from `docs/design.md` section 11 and attach the screenshots to the PR.
5. When the design intentionally changes, update `docs/design.md` in the same PR.
