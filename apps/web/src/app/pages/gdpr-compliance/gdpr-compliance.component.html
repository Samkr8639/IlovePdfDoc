Model A · In-Browser Sandbox

Merge, Split, Rotate, Compress, Protect, Unlock

Documents remain strictly within the device's local memory. Operations execute via WebAssembly and JavaScript (pdf-lib). Zero bytes of document content are transmitted across the network to any server.

Model B · Ephemeral Server-Assisted

PDF to Word Conversion

Documents stream securely over TLS 1.3 into volatile server RAM (multer.memoryStorage()). Files are held strictly for the duration of the conversion routine and auto-purged within max 60 minutes. No persistent disk writes occur.

Cookies & Consent Management
