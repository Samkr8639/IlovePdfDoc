Processing Architecture

How documents are processed: client-side vs. hybrid

Different document operations require different computing pipelines. Here is an honest, transparent breakdown of where execution takes place.

Model A · 100% Client-Side

In-Browser Processing (Local Runtime)

Merge PDF, Split PDF, Rotate PDF, Compress, Organize, Protect, Unlock, Remove Pages.

  1. 1
    Local File Selection

    Browser creates an isolated memory buffer via the HTML5 File API.

  2. 2
    Sandboxed WebAssembly Execution

    PDF parsing, page reordering, and cryptographic hashing run directly on your device CPU.

  3. 3
    Zero Network Transmission

    Zero document bytes travel across the internet. Files never reach our servers.

  4. 4
    Immediate Memory Clearance

    The resulting document writes to local disk; RAM buffers are destroyed when the tab closes.

✓ 100% client-side execution. Your files never leave your device.
Model B · Ephemeral Hybrid Service

Server-Assisted Conversion (Volatile RAM)

PDF to Word (DOCX) layout reconstruction requiring deep geometry analysis.

  1. 1
    Encrypted TLS 1.3 Transport

    Document is transmitted directly to our conversion engine over an encrypted TLS stream.

  2. 2
    Volatile Memory Storage Buffering

    Server holds the file in RAM buffers (multer.memoryStorage()). Never written to hard disk.

  3. 3
    Automated In-Memory Pruning

    Jobs have an automated pruning TTL of 60 minutes maximum (JOB_RETENTION_MS).

  4. 4
    Immediate Zeroization After Download

    Memory buffers are zeroed out immediately after DOCX delivery. Zero human inspection.

✓ Stateless ephemeral RAM. Zero persistent hard drive writes or storage.

Reviewer Note & Technical Guarantee

Unlike conventional web converters that upload all documents regardless of task complexity, we strictly reserve server assistance for tasks that cannot run client-side with full fidelity. In Edit PDF, editing happens entirely in your browser; only features explicitly marked with a cloud icon send the selected pages to our server, after you confirm, and they are deleted automatically after 10 minutes.
